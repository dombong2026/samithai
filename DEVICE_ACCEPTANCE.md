# Samith AI — physical-device QA acceptance

Playwright emulation does not count as real hardware testing. Record actual device, OS, browser, tester, release SHA, date and screenshot evidence.

| Device to test | Browser | Result |
|---|---|---|
| Physical iPhone | Safari | Untested |
| Physical Android phone | Chrome | Untested |
| Physical iPad | Safari | Untested |
| Physical Android tablet | Chrome | Untested |
| Windows laptop/desktop | Chrome + Edge | Untested |
| macOS laptop/desktop | Safari + Chrome | Untested |

Test login, registration, password recovery, email verification, theme/language selection, 200% zoom, text contrast, keyboard focus, search and product card grids. Verify 3-dot action menus, 10-row table pagination, centered CRUD modals, featured media, creator/admin workflows, legal terms and free checkout. Test RTL Arabic, support messaging, overflow, header alignment and accessibility. Confirm paid checkout is unavailable. Record issues, screenshots, failed steps and correction SHAs.

Approval is by an independent QA tester, not generated by CI.
