Live financial transactions and paid checkout are NOT enabled.

SHARED HOSTING / CPANEL / AAPANEL
1. Unzip the complete package to an application directory OUTSIDE the public document root.
2. Point the domain document root to the application's public/ directory, never to the project root.
3. Select PHP 8.3 or newer. Enable PDO MySQL, OpenSSL, Mbstring, XML and Fileinfo.
4. Ensure the application can write its .env, storage/ and bootstrap/cache/ directories.
5. Create a fresh EMPTY MySQL database and user in the hosting panel. Grant appropriate privileges.
6. Visit https://your-domain/installer .
7. Open the private .env file with your hosting File Manager and copy the generated INSTALL_TOKEN.
8. Enter the INSTALL_TOKEN, website URL, MySQL connection, administrator identity and password.
9. Click Install Samith AI. The wizard migrates the database, creates the administrator and locks setup.
10. Sign in at /login. Administrator dashboard: /dashboard. Customer account: /account.

SECURITY
Never publish .env, the installation token or MySQL credentials.
Never delete storage/app/installed.lock to reinstall an existing site.
Keep HTTPS enabled and confirm server permissions and login restrictions.
Do not activate paid purchases without a verified provider and end-to-end entitlement tests.

SECURITY / LEGAL RELEASE FLAGS
SAMITH_EMAIL_DELIVERY_ENABLED, SAMITH_REQUIRE_VERIFIED_EMAIL and SAMITH_REQUIRE_LEGAL_ACCEPTANCE
default to false until reviewed on a real configured host. MAIL_MAILER=log cannot send password reset tokens.
SAMITH_PAYMENTS_ENABLED remains false; no provider adapter is connected.

HOST ACCEPTANCE
GitHub CI performs a first install on a disposable MySQL database and then tests administrator login
after a fresh application start. This is not equivalent to real cPanel/aaPanel, backup restore or physical-device signoff.
Run separate independent acceptance before using this package for live customers.
