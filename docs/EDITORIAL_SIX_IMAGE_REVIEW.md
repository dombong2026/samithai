## Editorial workflow

1. Open a specific draft in the new Editorial Workflow review screen. Upload reviewed images to the existing Media Library and attach a featured image plus an optional social-sharing override.
2. Inspect the private preview and revise the SEO title, description and canonical URL using the existing SEO Manager.
3. Assign the actual reviewer, submit for review, and record a decision with human review notes and all four checklist acknowledgements: accuracy, SEO, media and rights.
4. Publication and scheduling still require an approval fingerprint of the current draft. Changing a featured/social image invalidates current approval and schedule; published image updates are blocked.
5. Maintain six article drafts as drafts until each receives genuine independent human review; starter prompt-product review is a separate workflow.

No automatic publication, migration or production upload is part of this feature branch commit.
